# Build a premium UGC campaign studio

**First impression**
- [x] The app should feel like a high-end creator command center: dark, fast, organized, and built for managing paid brand work.

**Features**
- [x] Create, view, edit, and delete campaigns for multiple brands.
- [x] Track campaign deliverables with due dates, platforms, and progress.
- [x] Open a campaign to see its brief, handles, recordings, deliverables, scripts, and insights.
- [x] Attach Instagram, TikTok, and YouTube handles to each campaign.
- [x] Record videos directly inside a campaign and automatically save them there.
- [x] Use a bottom recorder tab to capture a video first, then assign it to a campaign.
- [x] View each recorded video with per-video performance metrics.
- [x] Add scripts to campaigns and generate script ideas with an affordable AI writing assistant.
- [x] Show campaign-level social insights using connected handles, designed around future Apify-powered data.
- [x] Show an all-campaign insights page that summarizes every brand, account, campaign, and video.

**Design**
- [x] Premium dark studio aesthetic with black glass panels, electric cyan accents, and hot coral status highlights.
- [x] Campaign cards styled like polished production slates with brand identity, platform chips, due dates, and progress.
- [x] Cinematic recorder with campaign context and quick assignment flow.
- [x] Insights use bold metric tiles, platform-colored accents, and performance summaries.
- [x] App icon generated with a deep black background, neon cyan recording ring, and stylized creator slate mark.

**Pages / Screens**
- [x] **Campaigns**: List of brand campaigns with search, status, deliverables, and quick actions.
- [x] **Campaign Detail**: Full campaign workspace with recordings, scripts, handles, deliverables, and insights.
- [x] **Recorder**: Standalone bottom-tab recorder that saves a take and asks which campaign it belongs to.
- [x] **Insights**: Global dashboard for all campaigns, handles, videos, and platform performance.
- [x] **Scripts**: AI-assisted script workspace inside campaigns for hooks, talking points, and shot prompts.
- [x] **Campaign Editor**: Add or update brand name, campaign title, handles, and due dates.

**First version scope**
- [x] Build a polished local-first app experience with realistic campaign data and clean CRUD flows.
- [x] Include recorder entry points and real-device camera permission flow with a simulator-friendly camera message.
- [x] Design the insights layer so Apify-powered account/video fetching can be connected next without redesigning the app.
